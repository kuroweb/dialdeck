# 設定用 GATT サービス

Mac アプリがボタン画面の割り当てと、タッチパッドなどの設定を読み書きするための BLE GATT サービス。ファーム側は `firmware/main/config_service.c`、Mac 側は `mac/Sources/DialDeckKit/DeviceLink.swift`。

macOS は DialDeck をキーボードとマウスとして接続したままにする。Mac アプリはスキャンせず、接続済みの DialDeck を取得して同じ接続でこのサービスを使う。

## UUID

| 種類 | UUID |
| --- | --- |
| サービス | `98d3462c-2eb8-4022-ba87-4f253e72a24b` |
| info | `98d3462d-2eb8-4022-ba87-4f253e72a24b` |
| deck | `98d3462e-2eb8-4022-ba87-4f253e72a24b` |
| settings | `98d3462f-2eb8-4022-ba87-4f253e72a24b` |

## info（読み取り）

3 バイト: `[プロトコル版, スロット数, ラベル長]`。今はプロトコル版 2、スロット数 9、ラベル長 16。Mac アプリはプロトコル版が一致しないとき接続を止める。

## deck（読み取り・書き込み、暗号化必須）

ペアリング済みで暗号化された接続からだけ読み書きできる。

1 スロットは 20 バイト。

| オフセット | 長さ | 内容 |
| --- | --- | --- |
| 0 | 1 | 修飾キー（bit0 Control、bit1 Shift、bit2 Option、bit3 Command） |
| 1 | 1 | HID キーボードの usage。0 ならキーを送らない |
| 2 | 2 | Consumer control の usage（リトルエンディアン）。キーが 0 のときに使う |
| 4 | 16 | 表示名。UTF-8、NUL 終端、残りは 0 埋め |

スロット 0 が中央、1〜8 が上から時計回りの周りのボタン。

- 読み取り: 9 スロットを順に並べた 180 バイト
- 書き込み: `[スロット番号]` に続けて 1 スロット分、計 21 バイト。デバイスは NVS に保存し、ボタンの表示をすぐ更新する。範囲外のスロットや NUL の無い表示名は `Value Not Allowed` で拒否する

表示名に使える文字は、ファームのフォント（ASCII と LVGL の記号）に入っているものだけ。

## settings（読み取り・書き込み、暗号化必須）

設定画面と同じ値。リトルエンディアンの int32 を 6 個並べた 24 バイト。小数の値は 100 倍して入れる。

| オフセット | 内容 | 範囲 |
| --- | --- | --- |
| 0 | ポインタの速度（ゆっくり動かしたときの倍率） | 100〜500 |
| 4 | 加速（16 ms あたり 1 px 動くごとに足す倍率） | 0〜50 |
| 8 | 倍率の上限 | 100〜1000 |
| 12 | ノブ 1 目盛りあたりのスクロール量 | 1〜5 |
| 16 | スクロールの向き（0 通常、1 逆） | 0〜1 |
| 20 | 画面の明るさ（%） | 10〜100 |

- 読み取り: 今の値
- 書き込み: 24 バイトで全部を置き換える。範囲外の値が 1 つでもあれば何も変えず `Value Not Allowed` で拒否する。受け付けると、すぐに反映して NVS に保存し、デバイスの設定画面の表示も更新する
