# 設定用 GATT サービス

Mac アプリがボタン画面の割り当てと、タッチパッドなどの設定を読み書きし、herdr の agent をやり取りするための BLE GATT サービス。ファーム側は `firmware/main/config_service.c`、Mac 側は `mac/Sources/DialDeckKit/DeviceLink.swift`。

macOS は DialDeck をキーボードとマウスとして接続したままにする。Mac アプリはスキャンせず、接続済みの DialDeck を取得して同じ接続でこのサービスを使う。

## info（読み取り）

3 バイト: `[プロトコル版, スロット数, ラベル長]`。今はプロトコル版 5、スロット数 9、ラベル長 16。Mac アプリはプロトコル版 4 または 5 だけ受け付ける。

## deck（読み取り・書き込み、暗号化必須）

ペアリング済みで暗号化された接続からだけ読み書きできる。

1 スロットは 20 バイト。

| オフセット | 長さ | 内容 |
| --- | --- | --- |
| 0 | 1 | 修飾キー（bit0 Control、bit1 Shift、bit2 Option、bit3 Command） |
| 1 | 1 | HID キーボードの usage。0 ならキーを送らない |
| 2 | 2 | Consumer control の usage（リトルエンディアン）。キーが 0 のときに使う |
| 4 | 16 | 表示名。UTF-8、NUL 終端、残りは 0 埋め |

スロット 0 が中央、1〜8 が上から時計回りの周りのボタン。

- 読み取り: 9 スロットを順に並べた 180 バイト
- 書き込み: `[スロット番号]` に続けて 1 スロット分、計 21 バイト。デバイスは NVS に保存し、ボタンの表示をすぐ更新する。範囲外のスロットや NUL の無い表示名は `Value Not Allowed` で拒否する

表示名に使える文字は、ファームのフォント（ASCII と LVGL の記号）に入っているものだけ。

## settings（読み取り・書き込み、暗号化必須）

ポインタ、スクロール、明るさの設定。リトルエンディアンの int32 を 6 個並べた 24 バイト。小数の値は 100 倍して入れる。Sleep after の時間はデバイス内だけで保存し、この GATT 値には含めない。

| オフセット | 内容 | 範囲 |
| --- | --- | --- |
| 0 | ポインタの速度（ゆっくり動かしたときの倍率） | 25〜500 |
| 4 | 加速（16 ms あたり 1 px 動くごとに足す倍率） | 0〜300 |
| 8 | 倍率の上限 | 100〜1000 |
| 12 | ノブ 1 目盛りあたりのスクロール量 | 1〜5 |
| 16 | スクロールの向き（0 通常、1 逆） | 0〜1 |
| 20 | 画面の明るさ（%） | 1〜100 |

- 読み取り: 今の値
- 書き込み: 24 バイトで全部を置き換える。範囲外の値が 1 つでもあれば何も変えず `Value Not Allowed` で拒否する。受け付けると、すぐに反映して NVS に保存し、デバイスの設定画面の表示も更新する

## agents（書き込み、暗号化必須）

Mac アプリが herdr の agent の一覧を丸ごと書き込む。一覧が変わったときと、デバイスがつなぎ直したときに送る。一覧は 8 件ずつのページに分け、ページ 0 から順に 1 ページ 1 回で書き込む。1 回は最大 512 バイトで、1 パケットに収まらないときは long write になる。

`[ページ番号][ページ数][件数]` に続けて、agent ごとに次を並べる。件数は最大 8 で、最後のページ以外は 8。全体は最大 32 件（4 ページ）。デバイスは最後のページを受け取ったときに一覧を置き換える。順番が飛んだページは拒否する。

| 長さ | 内容 |
| --- | --- |
| 1 | 状態（0 blocked、1 done、2 working、3 idle、4 unknown）。この順に並べて送る |
| 1 + n | herdr の pane ID（agent コマンドの対象）。先頭 1 バイトが長さ、最大 23 バイト |
| 1 + n | タイトル（`terminal_title_stripped`）。UTF-8、最大 95 バイト |
| 1 + n | blocked の agent が聞いていること（`agent read --source detection` の最後の数行）。UTF-8、最大 159 バイト。blocked でなければ空 |

文字の途中で切らない。1 ページが 512 バイトを超えるときは、先に聞いていることを短くする。形式が崩れていれば `Value Not Allowed` で拒否し、前の一覧のまま変えない。

## usage（書き込み、暗号化必須）

Agents 画面の中央に出す、agent のプランの使用量。有効にした agent（Claude、Codex、Cursor）だけを、Mac の設定かデバイスの設定 → Usage、または Agents 画面の中央タップ（action の 6）で選べる。読み取りは Codex が 1 分、Claude と Cursor が 5 分ごと。429 などで失敗したら間隔を延ばし、前の値を送る。変わったときと、デバイスがつなぎ直したときに書き込む。

`[名前の長さ][名前][窓の数]` に続けて、窓ごとに `[ラベルの長さ][ラベル][使用率][リセットまでの分]`。

| 長さ | 内容 |
| --- | --- |
| 1 + n | 名前（`Claude` など）。最大 15 バイト。空なら使用量を出さない |
| 1 | 窓の数。最大 2 |
| 1 + n | 窓のラベル（`5h`、`7d` など）。最大 7 バイト |
| 1 | 使用率（%）。0〜100、255 は不明 |
| 2 | 送った時点からリセットまでの分（リトルエンディアン）。0xFFFF は不明 |

Mac アプリが GATT を版 3 の構成のまま覚えていて usage が見つからないときは、使用量を送らない。

## usage_sources（読み取り・書き込み・通知、暗号化必須、プロトコル版 5）

どの agent を使用量の候補にするか。1 バイトのマスク。bit0 が Claude、bit1 が Codex、bit2 が Cursor。デフォルトは 3 つともオン（`0x07`）。デバイスは NVS に保存し、設定画面の Usage でタップして切り替える。変わったときは通知する。

- 読み取り: 今のマスク
- 書き込み: 1 バイトで置き換える。下位 3 ビット以外は無視する
- 通知: デバイス側でマスクが変わったとき、同じ 1 バイトを送る

Mac アプリは接続時に読み、Agents の Usage sources と同期する。Mac でトグルしたときは書き込む。通知を受けたときも Mac 側を更新する。中央タップ（action 6）の順序は、このマスクと同じ。

## action（通知）

デバイスで agent を操作したとき、デバイスから Mac アプリに通知する。Mac アプリは接続時に購読する。

`[操作][ID の長さ][pane ID]`。操作は 1 Focus、2 Enter、3 Esc、4 上、5 下、6 次の使用量。

- Focus: herdr で workspace、tab、pane の順にフォーカスし、起動中のターミナルアプリを前面に出す
- Enter / Esc / 上 / 下: `agent send-keys` でそのキーを送る
- 次の使用量: Agents 画面の中央をタップしたときに送る。ID は空。Mac アプリは、usage_sources で有効な agent だけを Off → Claude → Codex → Cursor の順で 1 つ進め、usage を書き込み直す
